# Student Performance Prediction

This project predicts student final grades based on study hours, attendance, and assignment scores using a Linear Regression machine learning model.

## Project Overview

The goal of this project is to build a simple machine learning model that can predict a student's final grade based on academic factors such as study hours, attendance percentage, and assignment score.

This project was completed using Google Colab and Python.

## Tools and Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Dataset

A sample student performance dataset was created with the following features:

- Study Hours
- Attendance
- Assignment Score
- Final Grade

## Steps Performed

1. Created a student performance dataset
2. Loaded the dataset using Pandas
3. Checked dataset information and summary statistics
4. Visualized the relationship between study hours and final grade
5. Split the data into training and testing sets
6. Trained a Linear Regression model
7. Predicted student final grades
8. Evaluated model performance using MAE and R² Score

## Model Performance

- Mean Absolute Error: 0.66
- R² Score: 0.994

## Result

The model successfully predicted student final grades with high accuracy on the sample dataset.
